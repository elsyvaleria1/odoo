===================================
GPS Tracking - Asset HR Integration
===================================

Bridges GPS tracking with HR operator assignments, displaying driver/operator
information directly in the GPS dashboard and reports.

Features
========

* Show operator name in GPS device dashboard kanban cards
* Show asset license plate alongside device info
* Operator column in GPS devices list view
* Quick access to operator details from GPS dashboard
* Operator dimension in GPS Log Report (filter/group by driver)
* Vehicle trip report with attendance-based driver assignment

Usage
=====

Once installed, the module auto-activates when its dependencies are met:

1. Navigate to **IoT > GPS Tracking > Devices** to see operator info on device cards
2. Use the **Vehicle Trip Report** under Reports to analyze trips by driver
3. Filter GPS logs by operator in the pivot/graph views
