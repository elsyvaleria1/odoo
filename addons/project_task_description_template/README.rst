=================================
Project Task Description Template
=================================

This module allow to define description templates for a task and use
them to generate the description of the task.

**Table of contents**

.. contents::
   :local:

Usage
=====

To use this module:

Select the description template you want to use in a task.

Origin
======

Ported from `OCA/project <https://github.com/OCA/project>`_ and adapted for
the AgroMarin fork (Odoo 19.0). It has since diverged from upstream; do not
report its issues to the OCA.

Bug Tracker
===========

Bugs are tracked internally via the AgroMarin project management system.
In case of trouble, create a task under the relevant project.
